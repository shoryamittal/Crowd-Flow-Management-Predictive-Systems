## 1. Evidence Provenance Contract

Every displayed metric and exchanged payload within Sentinel AI must explicitly declare its evidence provenance.

```python
class EvidenceStatus(str, Enum):
    OBSERVED = "OBSERVED"        # Direct physical sensor/vision measurement
    CALCULATED = "CALCULATED"    # Deterministic mathematical deduction from defined inputs
    SCENARIO = "SCENARIO"        # Synthetic, calibrated, or operator-injected parameter
    PLANNED = "PLANNED"          # Future configuration or site-survey target
```

### 1.1 Provenance Envelope
Every numeric or critical telemetry value presented in the UI or API must be wrapped in a provenance descriptor:

```json
{
  "value": 120,
  "unit": "people",
  "timestamp_utc": "2026-09-09T16:30:00.000Z",
  "source": "cctv_ch01_fob_stairs",
  "evidence_status": "OBSERVED",
  "quality_state": "LIVE",
  "calibration_state": "UNCALIBRATED"
}
```

## 2. Named Zones & Route Graph Contracts

### 2.1 Zone Contract (`ZoneConfig` & `ZoneState`)
A sector consists of a directed graph of named physical zones.

```python
class ZoneRole(str, Enum):
    HOLDING_AREA = "HOLDING_AREA"
    APPROACH_CORRIDOR = "APPROACH_CORRIDOR"
    BOTTLENECK = "BOTTLENECK"
    DISPERSAL_DESTINATION = "DISPERSAL_DESTINATION"
    RELIEF_CORRIDOR = "RELIEF_CORRIDOR"
    EGRESS_EXIT = "EGRESS_EXIT"

@dataclass(frozen=True)
class ZoneConfig:
    zone_id: str                      # e.g., "zone_b_bottleneck"
    name: str                         # e.g., "Bottleneck B (FOB Stairs)"
    role: ZoneRole
    configured_operating_limit: float # C: Safe maximum capacity threshold
    physical_max_capacity: float      # Absolute structural limit
    unit: str = "people"

@dataclass
class ZoneState:
    zone_id: str
    current_count: float              # N(t): Current estimated occupants
    inflow_rate: float                # People per second arriving
    outflow_rate: float               # People per second departing
    net_growth_rate: float            # g = inflow - outflow
    last_updated_utc: datetime
    evidence_status: EvidenceStatus
    quality_state: str = "LIVE"
```

### 2.2 Route Contract (`RouteConfig`)
Connections between zones with physical flow constraints.

```python
class RouteStatus(str, Enum):
    OPEN = "OPEN"
    CLOSED = "CLOSED"
    UNVERIFIED = "UNVERIFIED"

@dataclass(frozen=True)
class RouteConfig:
    route_id: str                     # e.g., "route_h_to_b"
    source_zone_id: str
    target_zone_id: str
    max_flow_capacity: float          # Maximum clearance rate (pax/s)
    permitted_direction: str          # "UNIDIRECTIONAL" or "BIDIRECTIONAL"
    status: RouteStatus               # OPEN, CLOSED, or UNVERIFIED
    last_verified_utc: datetime
```

## 3. Observation & Perception Contracts

### 3.1 `ObservationSnapshot`
Generated by the Perception Engine upon processing a camera frame or video segment.

```python
@dataclass(frozen=True)
class ObservationSnapshot:
    snapshot_id: str                  # UUIDv4
    observed_at_utc: datetime
    frame_id: int
    frame_age_ms: float
    source: str                       # Camera index, RTSP URL, or video path
    source_mode: str                  # "CAMERA", "VIDEO", "SIMULATION"
    zone_id: str
    observed_value: float             # Detections or occupancy index
    unit: str                         # "relative_occupancy_index" or "people"
    evidence_status: EvidenceStatus   # Always OBSERVED
    quality_state: str                # "LIVE", "STALE", "CAMERA_LOST"
    calibration_state: str            # "UNCALIBRATED" or "CALIBRATED"
    model_version: str                # e.g., "yolov8n.pt"
    latency_ms: float
```

## 4. Forecasting & Prediction Contracts

### 4.1 `ForecastSnapshot`
Deterministic extrapolation computed by the Flow Forecast Engine.

```python
@dataclass(frozen=True)
class ForecastSnapshot:
    forecast_id: str
    zone_id: str
    created_at_utc: datetime
    evidence_snapshot_id: str
    horizon_seconds: float            # Typically 90.0 s
    current_count: float              # N
    operating_limit: float            # C
    net_growth_rate: float            # g
    modeled_limit_crossing_seconds: float | None # T_limit; None if g <= 0
    is_breached_now: bool             # True if N >= C
    predicted_count_at_horizon: float # N(horizon) = N + g * horizon
    sensitivity_min_seconds: float | None
    sensitivity_max_seconds: float | None
    calculation_validity: str         # "VALID", "FORECAST_UNAVAILABLE"
    invalidation_reason: str | None
    evidence_status: EvidenceStatus   # Always CALCULATED
```

## 5. Decision Safety Engine Contracts

### 5.1 `ActionCandidate`
Pre-approved tactical crowd control actions evaluated by the Decision Safety Layer.

```python
class ActionType(str, Enum):
    NO_ACTION = "NO_ACTION"
    UPSTREAM_METERING = "UPSTREAM_METERING"
    PERMITTED_DIVERSION = "PERMITTED_DIVERSION"

@dataclass(frozen=True)
class ActionCandidate:
    candidate_id: str                 # e.g., "action_meter_holding_h"
    action_type: ActionType
    title: str
    source_zone_id: str
    target_zone_id: str | None
    diverted_flow_rate: float         # pax/s diverted or withheld
    staff_response_delay_seconds: float # Time before staff can initiate (e.g., 8 s)
    planning_margin_seconds: float    # Safety margin (e.g., 5 s)
```

### 5.2 `ActionEvaluation`
Output of the Decision Safety Layer's connected-zone simulation for a candidate action.

```python
class FeasibilityStatus(str, Enum):
    FEASIBLE = "FEASIBLE"
    REJECTED = "REJECTED"

@dataclass(frozen=True)
class ActionEvaluation:
    candidate_id: str
    action_type: ActionType
    feasibility: FeasibilityStatus    # FEASIBLE or REJECTED
    rejection_reasons: list[str]      # e.g., ["Receiving corridor exceeds operating limit at t=48s"]
    affected_zones_summary: dict[str, Any] # State changes across H, B, R, etc.
    primary_zone_peak_count: float    # Peak count in Bottleneck B
    primary_zone_horizon_count: float # Count in B at t=90s
    added_waiting_cost: float         # Additional pax-seconds or queue added to Holding H
    usable_response_window_seconds: float # T_limit - delay - margin
    recommendation_validity_seconds: float # Duration this action remains operational
    evidence_status: EvidenceStatus   # Always CALCULATED
```

### 5.3 `DecisionRecommendation`
Top-ranked actionable recommendation presented to the operator.

```python
@dataclass(frozen=True)
class DecisionRecommendation:
    recommendation_id: str
    created_at_utc: datetime
    selected_candidate_id: str
    action_type: ActionType
    status: str                       # "ACTIVE", "EXPIRED", "NO_FEASIBLE_OPTION"
    valid_until_utc: datetime
    validity_duration_seconds: float
    summary_message: str
    tradeoffs_description: str
    evaluations: list[ActionEvaluation]
```

## 6. Human Operator Lifecycle Contracts

### 6.1 `OperatorActionLifecycle`
The 6-stage human-in-the-loop lifecycle. Transitions are strictly manual and auditable.

```python
class ActionLifecycleState(str, Enum):
    PROPOSED = "PROPOSED"            # Decision engine proposed; awaiting operator
    APPROVED = "APPROVED"            # Human operator clicked "Approve"
    DELIVERED = "DELIVERED"          # Command dispatched to field staff/marshals
    ACKNOWLEDGED = "ACKNOWLEDGED"    # Field marshal confirmed receipt via device/radio
    COMPLETED = "COMPLETED"          # Field team reports action execution finished
    VERIFIED = "VERIFIED"            # Subsequent CCTV observation confirms trend
```

### 6.2 `ActionTransitionEvent`
```python
@dataclass(frozen=True)
class ActionTransitionEvent:
    transition_id: str               # UUIDv4
    action_id: str                   # Associated recommendation/action ID
    incident_id: str                 # Parent incident ID
    from_state: ActionLifecycleState
    to_state: ActionLifecycleState
    actor_id: str                    # e.g., "StationMaster_Singh", "RPF_HeadConstable"
    timestamp_utc: datetime
    notes: str | None
    evidence_snapshot_id: str | None # Required for VERIFIED transition
```

## 7. Persistence & SQLite WAL Schema

The SQLite database (`data/sentinel.db`) operates with WAL (`PRAGMA journal_mode=WAL`) and stores durable records across three relational tables:

```sql
-- 1. Core Incidents Table
CREATE TABLE IF NOT EXISTS events (
    event_id TEXT PRIMARY KEY,
    schema_version INTEGER NOT NULL,
    created_at_utc TEXT NOT NULL,
    severity TEXT NOT NULL,
    primary_scenario TEXT NOT NULL,
    contributing_conditions TEXT,
    hotspot TEXT,
    load_anomaly REAL,
    accumulation REAL,
    redistribution REAL,
    recommended_action TEXT,
    action_code TEXT,
    source_mode TEXT,
    frame_id INTEGER,
    model_version TEXT,
    connectivity_state TEXT,
    local_status TEXT NOT NULL,
    sync_status TEXT NOT NULL,
    retry_count INTEGER NOT NULL DEFAULT 0,
    last_attempt_at TEXT,
    next_retry_at TEXT,
    synced_at TEXT,
    payload_json TEXT NOT NULL
);

-- 2. Decision Recommendations Table
CREATE TABLE IF NOT EXISTS decision_recommendations (
    recommendation_id TEXT PRIMARY KEY,
    incident_id TEXT,
    created_at_utc TEXT NOT NULL,
    selected_candidate_id TEXT NOT NULL,
    action_type TEXT NOT NULL,
    feasibility_status TEXT NOT NULL,
    valid_until_utc TEXT NOT NULL,
    evaluations_json TEXT NOT NULL,
    sync_status TEXT NOT NULL DEFAULT 'SYNC_PENDING',
    FOREIGN KEY(incident_id) REFERENCES events(event_id)
);

-- 3. Operator Action Lifecycle Transitions Audit Trail
CREATE TABLE IF NOT EXISTS action_transitions (
    transition_id TEXT PRIMARY KEY,
    action_id TEXT NOT NULL,
    incident_id TEXT NOT NULL,
    from_state TEXT NOT NULL,
    to_state TEXT NOT NULL,
    actor_id TEXT NOT NULL,
    timestamp_utc TEXT NOT NULL,
    notes TEXT,
    evidence_snapshot_id TEXT,
    sync_status TEXT NOT NULL DEFAULT 'SYNC_PENDING',
    FOREIGN KEY(incident_id) REFERENCES events(event_id)
);
```

### 8.4 `POST /api/operator/action/transition`
Executes an auditable manual transition in the action lifecycle.
- **Request Body:**
```json
{
  "action_id": "ACT-METER-001",
  "incident_id": "INC-2026-9901",
  "from_state": "PROPOSED",
  "to_state": "APPROVED",
  "actor_id": "StationMaster_Sharma",
  "notes": "Approved upstream metering at Gate 2 holding area"
}
```
- **Allowed Transitions:**
  - `PROPOSED` → `APPROVED`
  - `APPROVED` → `DELIVERED`
  - `DELIVERED` → `ACKNOWLEDGED`
  - `ACKNOWLEDGED` → `COMPLETED`
  - `COMPLETED` → `VERIFIED` (requires `evidence_snapshot_id` proving trend reversal)
